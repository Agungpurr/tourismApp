# 🏝️ Tourism App - Flutter

Aplikasi wisata berbasis Flutter untuk menjelajahi destinasi wisata dengan tampilan yang menarik dan informatif.

---

## ✨ Fitur Utama

- **Daftar Destinasi Wisata** — Jelajahi berbagai tempat wisata menarik
- **Detail Tempat** — Informasi lengkap setiap destinasi
- **Kategori Wisata** — Filter wisata berdasarkan kategori
- **Tampilan Modern** — UI yang bersih dan responsif

---

## 🗂️ Struktur Proyek

```
lib/
├── data/            # Model data dan sumber data wisata
├── provider/        # State management dengan Provider
├── screen/          # Halaman-halaman aplikasi
├── static/          # Aset statis (gambar, konstanta)
├── style/           # Tema, warna, dan gaya UI
└── main.dart        # Entry point aplikasi
```

---

## 🚀 Cara Menjalankan

### Prasyarat

- Flutter SDK (versi terbaru)
- Dart SDK
- Android Studio / VS Code

### Instalasi

```bash
# Clone repositori
git clone https://github.com/Agungpurr/tourismApp.git

# Masuk ke direktori proyek
cd tourismApp

# Install dependencies
flutter pub get

# Jalankan aplikasi
flutter run
```
